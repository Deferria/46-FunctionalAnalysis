# Abstract

泛函分析 Functional Analysis 是分析学的一个分支, 主要研究赋范线性空间、Banach 空间、Hilbert 空间等抽象空间的性质和结构, 以及线性算子在这些空间上的行为. 它在数学分析、微分方程、量子力学等领域有广泛的应用.

本项目为上海交通大学数学科学学院开设的【泛函分析】课程笔记, 主要来源于课堂内容, 并加以后期整理、添加实例与例子、添加延伸知识、添加个人总结等得到, 并模块化归类, 分为定义、定理、性质、实例等不同环境盛放不同类型的内容.
